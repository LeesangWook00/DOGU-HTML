# 2026 상반기 리뷰 & 하반기 목표설정 / 연말 평가 (DOGU) v4.0.0

`Untitled-1 - 복사본.html`에서 실행하는 DOGU 인사평가 문서입니다. 2026년 상반기 업무 리뷰, 하반기 목표 설정, 연말 평가를 하나의 HTML 파일에서 작성하고 관리합니다.

## 주요 기능

- 기본정보, 상반기 업무 리뷰, 하반기 목표와 역량 개발 목표 작성
- 1차, 2차, 3차 평가 단계별 승인 및 평가 기록
- Manager와 이사급 이상의 직급별 종합 점수 가중치 적용
- Seed, Root, Plant, Grow, Bloom 평가 체계 지원
- 로컬 임시저장 및 불러오기
- JSON 내보내기 및 불러오기
- 확정 단계 잠금과 잠금 데이터 무결성 확인
- HR 모드에서 평가 설정 및 템플릿 관리
- Jira 이슈 작성 화면 연결

## 실행 방법

### VS Code에서 실행

1. 저장소를 VS Code로 엽니다.
2. `Untitled-1 - 복사본.html` 파일을 엽니다.
3. 파일을 마우스 오른쪽 버튼으로 클릭합니다.
4. **Open with Live Server**를 선택합니다.

Live Server 확장이 없다면 VS Code 확장 메뉴에서 `Live Server`를 설치합니다.

### 브라우저에서 직접 실행

HTML 파일을 브라우저로 직접 열어도 기본 기능을 사용할 수 있습니다. 다만 Live Server를 사용하면 파일 변경 시 페이지가 자동으로 새로고침됩니다.

## 화면 구성

문서는 다음 순서로 구성되어 있습니다.

1. **파일 작업 영역**: 로컬 임시저장, JSON 불러오기/내보내기, Jira 연결, 초기화
2. **기본정보**: 성명, 소속/팀, 직급
3. **Part 1 - 상반기 업무 리뷰**: 상반기에 수행한 프로젝트와 업무 성과, 본인 코멘트
4. **Part 2 - 하반기 목표설정**: 업무 목표, 목표 가중치, 역량 개발 목표
5. **Part 3 - 하반기 목표 정렬 및 승인**: 1차부터 3차까지의 승인 흐름
6. **Part 4 - 연말 평가**: 목표 평가, 역량 평가, 태도 점수, 최종 결과

## 작성자 사용법

1. 성명, 소속/팀, 직급을 입력합니다.
2. 상반기 프로젝트 또는 업무를 입력하고 각 업무의 리뷰 내용을 작성합니다. 프로젝트가 부족하면 **프로젝트 추가**를 사용합니다.
3. 본인 리뷰 종합 코멘트를 작성합니다.
4. 하반기 업무 목표와 역량 개발 목표를 입력합니다.
5. 업무 목표의 가중치 합계가 100%인지 확인합니다. 합계가 100%가 아니면 제출 또는 내보내기가 제한될 수 있습니다.
6. **JSON 내보내기**를 눌러 작성 파일을 저장합니다.
7. 저장한 JSON 파일을 다음 평가자에게 전달합니다.

### 작성 중 임시저장

- **로컬 임시저장**: 현재 브라우저에 작성 내용을 저장합니다.
- **임시저장 불러오기**: 같은 브라우저에 저장된 내용을 다시 불러옵니다.
- **JSON 내보내기**: 다른 사람에게 전달할 수 있는 파일을 다운로드합니다.
- **JSON 불러오기**: 전달받은 평가 파일을 현재 화면에 표시합니다.

로컬 임시저장은 브라우저별로 관리되므로 다른 PC나 다른 브라우저에서는 사용할 수 없습니다. PC를 바꾸거나 평가자에게 전달할 때는 JSON 내보내기를 사용합니다.

## 평가자 사용법

1. 작성자로부터 받은 JSON 파일을 **JSON 불러오기**로 엽니다.
2. 현재 평가 단계가 본인의 단계인지 상단 모드 표시를 확인합니다.
3. 해당 단계의 목표 점수와 역량 점수를 입력합니다.
4. 필요한 코멘트와 승인 정보를 입력합니다.
5. **JSON 내보내기**로 다음 평가자에게 전달할 파일을 저장합니다.
6. 모든 평가 단계가 끝나면 최종 평가자가 면담 및 서명 절차를 진행합니다.

평가 단계는 HR 설정에 따라 1차, 2차, 3차 중 일부만 사용될 수 있습니다. 다른 평가자의 입력 내용을 임의로 덮어쓰지 않도록 전달받은 최신 JSON 파일을 기준으로 작업해야 합니다.

## HR 사용법

HR은 **HR 설정**에서 평가 단계와 워크플로우를 관리할 수 있습니다.

- 연초 또는 하반기 목표설정에 사용할 평가 단계 지정
- 연말 평가에 사용할 평가 단계 지정
- 평가자별 가중치 설정
- 배포용 템플릿 JSON 생성
- 직원 JSON 취합 및 평가 결과 관리

HR 모드는 화면의 **HR 설정** 버튼 또는 지정된 단축키로 진입합니다. HR 코드를 잊어버린 경우에는 브라우저의 저장 데이터만으로 복구할 수 없으므로 관리 담당자에게 문의해야 합니다.

## 점수 계산 방식

평가 단계의 점수는 다음 순서로 종합됩니다.

- 평가 등급: `Seed` → `Root` → `Plant` → `Grow` → `Bloom`
- 목표별 성과 점수: 목표 가중치를 적용한 평균
- 역량 점수: 회사 공통 역량 항목의 평균
- 평가자 점수: 활성화된 평가 단계의 설정 비율로 합산
- Manager: 성과 60%, 역량 30%, 태도 10%
- 이사급 이상: 성과 60%, 역량 40%

일부 점수가 아직 입력되지 않은 경우 입력된 항목을 기준으로 계산되며, HR이 조정 점수를 입력하면 최종 점수에 조정값이 적용됩니다.

## Jira 연결

화면 상단의 `JSON 내보내기` 옆에 있는 **Jira 연동하기** 버튼을 사용합니다.

처음 사용할 때 화면의 Jira 영역에서 다음 정보를 입력합니다.

- Jira 주소: 예시 `https://회사명.atlassian.net`
- 프로젝트 키: 예시 `HR`
- 이슈 유형: 기본값 `Task`
- 이슈 제목: 비워두면 성명과 소속/팀으로 자동 생성

입력 후 상단의 **Jira 연동하기** 버튼을 누르면 Jira 이슈 작성 화면이 새 창으로 열립니다. Jira 로그인은 Jira 화면에서 진행하며, 이 HTML 파일에는 비밀번호나 API 토큰을 입력하지 않습니다.

Jira 연결 설정은 현재 브라우저의 `localStorage`에 저장됩니다. 다른 컴퓨터나 다른 브라우저에서는 다시 입력해야 합니다.

### Jira 연결이 열리지 않는 경우

- Jira 주소에 회사의 실제 Jira 도메인을 입력했는지 확인합니다.
- 프로젝트 키는 프로젝트 이름이 아니라 Jira 프로젝트의 키를 입력합니다.
- 브라우저에서 팝업 차단이 해제되어 있는지 확인합니다.
- Jira 로그인 권한과 해당 프로젝트의 이슈 생성 권한이 있는지 확인합니다.
- 연결 설정을 바꾸려면 **연동 설정 지우기**를 누른 뒤 새 값을 입력합니다.

## 데이터 보관 및 보안 안내

- 작성 중인 데이터는 브라우저 로컬 저장소 또는 사용자가 직접 내보낸 JSON 파일에 보관됩니다.
- JSON 파일에는 평가 관련 입력 내용이 포함될 수 있으므로 안전한 경로로 전달해야 합니다.
- 브라우저 캐시 또는 로컬 저장소를 삭제하면 임시저장 데이터가 사라질 수 있습니다.
- HR 코드는 소스에 평문으로 저장하지 않고 해시 형태로 확인합니다.
- 잠금 데이터 무결성 검사는 변경 의심을 알리는 1차 확인 기능이며, JSON 파일의 위변조를 완전히 차단하는 기능은 아닙니다.

## 문제 해결

### 버튼을 눌러도 반응이 없는 경우

페이지를 새로고침하고, VS Code의 Live Server로 다시 실행합니다. 브라우저 개발자 도구에 오류가 표시되면 오류 내용과 발생한 버튼을 함께 확인합니다.

### JSON 파일이 열리지 않는 경우

파일이 이 문서에서 생성된 JSON인지 확인합니다. 파일을 텍스트 편집기로 임의 수정했거나 내용이 일부 잘린 경우 불러오기에 실패할 수 있습니다.

### 작성 내용이 사라진 경우

같은 브라우저의 **임시저장 불러오기**를 먼저 시도합니다. 임시저장이 없다면 전달받은 JSON 파일을 사용해야 하며, 브라우저 데이터 삭제 후에는 로컬 임시저장을 복구할 수 없습니다.

### GitHub에서 실행하는 경우

GitHub 저장소에서 HTML 파일을 클릭하면 소스 코드가 표시될 수 있습니다. 웹 페이지로 실행하려면 GitHub Pages를 활성화하거나 HTML 파일을 내려받아 브라우저 또는 Live Server로 엽니다.
